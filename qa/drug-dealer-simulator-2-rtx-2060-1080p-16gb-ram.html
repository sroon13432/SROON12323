What limits you first

  • Memory is not the limit. 16 GB covers the 16 GB this game asks for, so any stutter you see will come from the graphics card, a hard drive, or the CPU rather than from RAM.
  • Storage is a size question, not a speed one. The store page lists 32 GB available space; the publisher does not require an SSD, so free space is the only thing to check.
  • The CPU assumption. Every frame rate on this page assumes a processor at or above the published minimum, Intel Core i5-8400 / AMD Ryzen 3 3200G or equivalent. If yours is older, the GPU figure is the ceiling and the CPU decides how far below it you land.

Settings to start from

  1. Keep your GPU driver on the latest Game Ready / Adrenalin branch before comparing frame rates.
  2. If frame pacing stutters, lower Shadows, Volumetric Lighting and Ambient Occlusion one step each.
  3. Keep the recommended preset and drop shadow quality one notch: it is the single largest cost in most modern renderers and the least visible in motion.
  4. Leave ray tracing off unless you have a card that supports hardware upscaling with it; the reflections are not worth half your frame rate on this tier.
