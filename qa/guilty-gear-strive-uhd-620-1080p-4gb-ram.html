What limits you first

  • Memory is at the minimum, not the recommendation. With 4 GB against a 8 GB recommendation, background apps (browser tabs, Discord, recording software) are competing with the game. Close them before you judge the frame rate.
  • Storage is a size question, not a speed one. The store page lists 30 GB available space; the publisher does not require an SSD, so free space is the only thing to check.
  • The CPU assumption. Every frame rate on this page assumes a processor at or above the published minimum, AMD FX-4350, 4.2 GHz / Intel Core i5-3450, 3.10 GHz. If yours is older, the GPU figure is the ceiling and the CPU decides how far below it you land.
  • No dedicated video memory. This graphics solution borrows from system RAM, so the memory figure above is shared with the operating system and the game has less of it than the number suggests.

Settings to start from

  1. If frame pacing stutters, lower Shadows, Volumetric Lighting and Ambient Occlusion one step each.
  2. Use Fullscreen mode instead of Borderless Windowed to cut input latency and gain a few FPS.
  3. Start at Low, then raise one setting at a time - shadows, foliage and volumetric fog cost the most frames per unit of visible difference in this kind of scene.
  4. Turn on upscaling if the game offers it (DLSS on GeForce, FSR or XeSS on anything else). At Quality it usually returns 25-40% of the frame rate for a small sharpness cost at 1080p.
