What limits you first

  • Storage is a size question, not a speed one. The store page lists 46+ GB available space; the publisher does not require an SSD, so free space is the only thing to check.
  • The CPU assumption. Every frame rate on this page assumes a processor at or above the published minimum, AMD FX 6300 @ 3.8 GHz, Ryzen 3 - 1200, Intel Core i5 2400 @ 3.1 GHz (MORE DETAILS HERE). If yours is older, the GPU figure is the ceiling and the CPU decides how far below it you land.
  • Handheld resolution. At 800p the Deck's 1280x800 panel does a lot of the work for it; a dock pushing 1080p to a TV costs roughly 40% of the frame rate for the same settings.
  • No dedicated video memory. This graphics solution borrows from system RAM, so the memory figure above is shared with the operating system and the game has less of it than the number suggests.

Settings to start from

  1. If experiencing frame drops, lower Volumetric Lighting and Shadow Quality to Medium.
  2. Enable Fullscreen mode over Borderless Windowed to reduce input latency.
  3. Start at Low, then raise one setting at a time - shadows, foliage and volumetric fog cost the most frames per unit of visible difference in this kind of scene.
  4. Turn on upscaling if the game offers it (DLSS on GeForce, FSR or XeSS on anything else). At Quality it usually returns 25-40% of the frame rate for a small sharpness cost at 1080p.
