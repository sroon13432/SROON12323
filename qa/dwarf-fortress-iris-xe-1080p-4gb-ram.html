What limits you first

  • Memory is not the limit. 4 GB covers the 4 GB this game asks for, so any stutter you see will come from the graphics card, a hard drive, or the CPU rather than from RAM.
  • Storage is a size question, not a speed one. The store page lists 500 MB available space; the publisher does not require an SSD, so free space is the only thing to check.
  • The CPU assumption. Every frame rate on this page assumes a processor at or above the published minimum, Dual Core CPU - 2.4GHz+. If yours is older, the GPU figure is the ceiling and the CPU decides how far below it you land.
  • No dedicated video memory. This graphics solution borrows from system RAM, so the memory figure above is shared with the operating system and the game has less of it than the number suggests.

Settings to start from

  1. Use Fullscreen mode instead of Borderless Windowed to cut input latency and gain a few FPS.
  2. Keep your GPU driver on the latest Game Ready / Adrenalin branch before comparing frame rates.
  3. The recommended preset is the starting point, not the ceiling - you have headroom to raise texture and shadow quality until the frame rate drops below your target.
  4. Cap the frame rate just under your refresh rate rather than leaving it uncapped; a steady frame time at 60 feels better than a swinging 70-90.
