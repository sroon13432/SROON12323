Microsoft's Github posts message celebrating efforts to port PlayStation 5 version of Grand Theft Auto 6 to PC, then quickly deletes it

PC Gamer · industry report·26 November 2026·Source

Microsoft-owned developer platform Github stepped in it earlier today when it posted a message on X celebrating the success of AnyPS5, an open source project that aims to let users port PS5 executables to PC, and then linked that success directly to efforts to port Grand Theft Auto 6 to PC. The message was deleted shortly after it was posted, but not before it was widely noticed and called out for being a very bad idea.

"The repo AnyPS5 has passed 58K stars since its August launch, rewriting PS5 executables to run on Windows and Linux. Does changing where games run cross a legal line? Share your take. Happy GTA VImas!"

More from the report

  • Lest there be any misunderstanding, a video that accompanied the post made the GTA 6 connection explicit: "The project rewrites a game's executable so Windows and Linux can run it directly.
  • The question of whether or not this sort of thing crosses a legal line has, predictably, sparked debate among those who think they have a clear understanding of the answer.
  • That point wasn't missed by redditors, one of whom described it as Github " openly taunting Sony and Rockstar." Even the AnyPS5 subreddit seemed baffled: Redditor superkickstart asked,
  • There's also a little bit of irony in the fact that, until earlier this week, the leading effort to get GTA 6 running on PC was based on an Xbox build of the game posted by GTA 6 leaker…
