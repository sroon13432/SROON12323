Workshop Security Update

POSTAL 2 · posted by the game's developer on Steam·23 November 2026·Source

First, and coming soon, is the long awaited Apple silicon update for both POSTAL 2 and Paradise Lost, meaning any Mac with an M series chip can now run the game. This will also update all versions of the game to X64 too, ensuring compatibility long into the future on every platform.

This update is not exciting in and of itself, it's to plug a security hole that was flagged to us, where it was possible to for someone to push a workshop mod that could execute files on someone else's PC.

What the notes say

  • While we're here though, we can at least tease you a bit about some future updates, as we are spinning support for POSTAL 2 classic back up while we wait POSTAL 2 Redux.
  • With the help from Teem Beef, we have also swapped out from the old Karma Math physics engine to the more modern Jolt physics engine.
  • The main reason for doing so is we have never had the source code for the Karma engine, and there are game crashes tied to it we could never fix.
  • Further out we will be adding more optional features and improvements to P2, and also improving the SDK and workshop integration, so watch this space!

Quoted from the announcement itself, shortened where a line ran long.
