Factorio 2.1.25 released as stable

Factorio · posted by the game's developer on Steam·23 November 2026·Source

The "Starting RCON interface" log line now shows the port that was actually bound, so --rcon-port 0 or --rcon-bind ADDRESS:0 can be used to let the system pick a free port.

Rail building when using ghosts (e.g. in remote view or with ghost cursor) defaults to manual rail planning again. Rail planner pathfinding can be toggled with shift. more

What the notes say

  • Added depleted mining drill filter to deconstruction planner.
  • Added fluid system contents and flushing functionality to the pipe GUI.
  • Added search to the 'Select planet to drop to' GUI.
  • Added build sounds and growth sounds for Yumako, Jellystem and Nauvis tree.
  • Joining a public game hosted on your own local network now works even on routers without NAT loopback.
  • Changed GUI parametrise icon. more

Quoted from the announcement itself, shortened where a line ran long.
