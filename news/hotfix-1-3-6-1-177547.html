Hotfix - 1.3.6.1.177547

SCUM · posted by the game's developer on Steam·12 November 2026·Source

The hotfix also restores chat message colors, improves Cyrillic text readability and includes several other fixes. We’ve also corrected Steam’s default controller template, which prevented some controllers from working automatically in-game.

Corrected an issue where the default controller template was not set in Steam, preventing some controllers from working automatically in-game. Players can still choose a different template or create their own.

What the notes say

  • Players can still choose a different template or create their own.
  • Fixed an issue where closing the pause menu after a controller disconnection could override restrictions on character input during the tutorial.
  • As always, if you encounter anything else that requires our attention, please let us know through one of the following channels:
  • Please include whether you’re playing in single-player or multiplayer, the server name where applicable, and what happened.
