3.1.1 Bug Fixes (October 23)

Once Human · posted by the game's developer on Steam·23 October 2026·Source

Fixed an issue where Halloween Wonder Night event task progress was not retained across seasons. We will compensate the lost Blind Box attempts caused by the progress loss across seasons via mail within 2 business days. Please check your mail.

Fixed an issue in custom servers where duplicate character name warnings would not appear, preventing players from entering the server.

What the notes say

  • Fixed an occasional issue where the ship would get stuck while sailing, causing players to be teleported to the wrong location.
  • Fixed an issue where applying a ship design layout with "Building Filter" - "Ignore Facilities" checked could prevent the ship from being placed properly.
  • We have received numerous reports from players that the Calamity Owl in strongholds may get stuck underground while moving, preventing players from attacking it normally.
  • This issue is currently being addressed, and we will complete the fix as soon as possible.
  • We have received numerous reports from players about the issue of crocodile patterns being lost when transferring out of Eternaland.
  • We have identified the cause of this issue; however, since the fix involves some model changes, it will need to be completed with the next version update (November 5).

Quoted from the announcement itself, shortened where a line ran long.
