October 26, 2026 Update

Half-Life: Alyx · posted by the game's developer on Steam·26 October 2026·Source

Add a setting under Advanced Performance to enable Foveated Rendering on desktop for supported hardware (for DirectX: NVIDIA GTX 16XX+, RTX 20XX+; for AMD: RX6xxx+ requires launching with -vulkan). Can increase rendering performance. Enable eye-tracking on your headset for best results. More information here.

What the notes say

  • Add a setting under Advanced Performance to enable Foveated Rendering on desktop for supported hardware (for DirectX: NVIDIA GTX 16XX+, RTX 20XX+;
  • Enable stencil buffer tagging when running natively on Steam Frame to help improve reprojection quality.
  • Fix several rendering crashes common in workshop content.
  • Fix "Gnome Alone" achievement failing to unlock for some users.
  • (10/28) Fix performance regression introduced by 10/26 build for AMD graphics cards users.
  • (10/28) Fix visual glitches on decals and splatters when Foveated Rendering is enabled.

Quoted from the announcement itself, shortened where a line ran long.
