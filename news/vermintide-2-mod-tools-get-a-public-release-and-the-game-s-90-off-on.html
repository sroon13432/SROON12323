Vermintide 2 mod tools get a public release, and the game's 90% off on Steam too

PC Gamer · industry report·27 November 2026·Source

Though Vermintide 2's had a Steam Workshop since 2018, it's mostly used for quality-of-life stuff like UI tweaks. That's set to change now that Fatshark has announced a public release of its internal developer tools, which they say "will allow modders to work their magic on both editing and creating anything from custom levels, models, textures, particles, animations, and more!"

Right now, only a select number of sanctioned mods can be used in Vermintide 2's "official realm" which is the one with loot and leveling that carries over, while unsanctioned mods can only be accessed in a "modded realm" where there are no progression systems. Obviously that's off-putting to a lot of players, so Fatshark has announced a change.

More from the report

  • "We have an update releasing in early December which will see the Modded Realm have its own, local, offline progression.
  • I'm not sure how many players will be happy to start over from level one just to get access to a wider variety of mods, but I hope it encourages some folks to check them out.
  • That shutdown is planned for early December, at the same time as the update that adds local progression to the modded realm.
  • Finally, Fatshark mentioned that focusing on the mod tools to get them ready for public release had to take priority from other updates.
