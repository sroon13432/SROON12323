Patch v1.13.5.0

Barotrauma · posted by the game's developer on Steam·27 October 2026·Source

We have just released a patch to fix newly discovered multiplayer exploits as well as to pre-empt issues following Barotrauma's removal from Epic Games Store. See the list of changes below and be sure to update your game!

Fixed an exploit that allowed modified clients to bypass the server's DoS filter and to cause other clients to get kicked/banned instead of them.

What the notes say

  • Disabled crossplay support with Epic Online Services due to the game being removed from the Epic Games Store.
  • Fixed an exploit that allowed modified clients to freeze the server by sending malicious data.
  • Fixed an exploit that allowed modified clients to issue hidden orders to NPCs.*
  • Fixed an exploit that allowed modified clients to remotely placely detonators and other attachable items to trigger "remote explosions". *
  • Fixed an exploit that allowed modified clients to bypass the server's DoS filter and to cause other clients to get kicked/banned instead of them.
  • Fixed an exploit that allowed modified clients to send the server data that would corrupt the campaign save the next time the game is saved.*

Quoted from the announcement itself, shortened where a line ran long.
