Halloween 2026

Supermarket Together · posted by the game's developer on Steam·30 October 2026·Source

Hello! It’s that time of the year again, the update brings back the Halloween ghosts event and a new layout. A reminder that if you own at least a store from Classic and another from Plaza you can move up to 2000 dollars each day to this new layout for a quick start using the Logistics Desk in devices.

The event will go on for around 2-3 weeks, then a small patch will remove it. Next update should be before Christmas if no major force prevents it.

What the notes say

  • New layout is now available: The Big One, which is around twice the size of layouts released so far. Note that:
  • Experimentally this layout features more increasingly customers than normal, up to +80 by a certain day. Expect some extra customers from day one.
  • The perks tree has 5 starting points, which one will give the most profit for a quick start?
  • Tutorial is automatically skipped for this layout.
  • It features bigger paintable chunks for less detrimental performance, however a version with the smaller tiles could be considered if there’s global interest in it.
  • Ghost event is back! The Whimsical Pumpkin is available to be placed from the decoration tab, the more pumpkins placed the more ghosts will spawn.

Quoted from the announcement itself, shortened where a line ran long.
