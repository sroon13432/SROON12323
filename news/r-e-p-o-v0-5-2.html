R.E.P.O. v0.5.2

R.E.P.O. · posted by the game's developer on Steam·18 November 2026·Source

Object Shadow Quality - Added a new graphics setting to disable shadows cast by smaller objects. Try this if you're experiencing performance issues on the new map!

Save Files - Save file backups are now capped at 3 per save to reduce unnecessary Steam Cloud usage. Cosmetic data backups have been increased from 1 to 3.

What the notes say

  • Object Shadow Quality - Added a new graphics setting to disable shadows cast by smaller objects. Try this if you're experiencing performance issues on the new map!
  • Video Overlay Effect - Slightly reduced strength.
  • Minecart - Lowered the volume of some sounds.
  • Enemy Gnomes - Lowered the sound volume for the Halloween version.
  • Shop Extraction - An extraction in progress now delays leaving instead of blocking it.
  • Save Files - Save file backups are now capped at 3 per save to reduce unnecessary Steam Cloud usage. Cosmetic data backups have been increased from 1 to 3.

Quoted from the announcement itself, shortened where a line ran long.
