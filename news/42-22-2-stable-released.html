42.22.2 STABLE Released

Project Zomboid · posted by the game's developer on Steam·9 November 2026·Source

After updating, when you launch the game and select 'Continue' or 'Load', you will be asked to 'convert' your save for the new update. Once you click yes, a backup of your existing save is created in the same folder with '_backup' added to the file name. This means if you do have any problems, you have a backup automatically available.

If your existing save game uses mods, it's possible that some mods may not work with the latest build. We would still recommend converting your save and seeing if your mods work, as you'll have the automatic backup available if you have issues. You can also manually backup your save by copying it.

What the notes say

  • We would still recommend converting your save and seeing if your mods work, as you'll have the automatic backup available if you have issues.
  • If you wish to continue to wait until mod creators update mods that you use frequently, you can continue to play on build 42.21.
  • In your Steam Library, right click the entry for Project Zomboid and click 'Properties', then select 'Game Versions & Betas' and select '42.21' from the list.
  • This will automatically update your client back to version 42.21 and your save / mods should work.
  • Players will have the option to sleep disabled, with an explanatory tooltip, when subjected to an active Bad Smell moodle.
  • Player-crafted makeshift radios no longer have randomized encumbrance values and instead use the encumbrance value of their corresponding tiles.

Quoted from the announcement itself, shortened where a line ran long.
