Open Beta for Performance

Cities: Skylines II · posted by the game's developer on Steam·28 October 2026·Source

This Beta includes improvements to almost every LOD model of the base game buildings, which should improve rendering performance, especially on lower-end hardware, updates to the upscaler support (DLSS, FSR3, FSR 4, and XeSS 3), an update to the Coherent UI framework, and a new visual update adding additional texturing under roads! You can freely switch between the Open Beta version and the current live version, and save games will keep working between the two.

Please note that this update includes changes to the Virtual Texturing, which requires a full redownload of the game as it touches many base game assets!
