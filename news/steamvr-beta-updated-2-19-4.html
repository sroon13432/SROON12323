SteamVR Beta Updated - 2.19.4

SteamVR · posted by the game's developer on Steam·19 November 2026·Source

The Steam Link for Meta Quest FAQ is available here. Please note that this requires opt-in to the Steam Link for Meta Quest Beta, here (or via the “Release Channels” under Steam Link in application settings in headset), as well as selecting SteamVR Beta from the Betas list in your SteamVR Properties in Steam.

If you encounter issues with this update, please post in the SteamVR Bug Report forum. If possible, include a system report to help us investigate.

What the notes say

  • Replies to this announcement are not tracked for bug reporting purposes.
  • On laptops with two GPUs, Steam Link now uses the high-performance GPU, unless a Windows graphics preference is set for SteamVR.
  • Increased the default recommended render resolution for streamed PC VR applications (render scale 1.5, targeting 1.4× the headset's panel resolution).
  • Improved color clarity, using higher-quality filter to downsample color before encoding, preserving fine colored details.
  • A new system-layer rendering pipeline renders foveated and non-foveated views directly from their source textures, eliminating an intermediate render texture and an extra resampling step.
  • Adjust the size of the sharp foveated region for the SteamVR interface, choosing a narrower, sharper area or a wider area.

Quoted from the announcement itself, shortened where a line ran long.
