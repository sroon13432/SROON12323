About the New "Fullpackage" Download Mode on Steam

Wuthering Waves · posted by the game's developer on Steam·18 November 2026·Source

Since Version 3.0, we have been receiving feedback from Rovers regarding package size optimization. To address this, we have been working to reduce package sizes and have introduced such features as Tiered Client Resource Downloads and PC Resource Cleanup. Meanwhile, it came to our attention that updating the game via Steam required a much larger download size than via the official client, and pre-download was not supported.

Since the release of the launcher on Steam in Version 3.8, we have received valuable feedback from the community: some Rovers preferred downloading and launching the game directly on Steam. We take this feedback seriously, and the development team has decided to add a second download mode, titled "Fullpackage," to the existing one. The Fullpackage option has the original download and update mechanics, allowing you to download the complete package and launch the game directly via Steam.

What the notes say

  • Path: Go to "Library" -> Right-click "Wuthering Waves" -> Select "Properties" -> Select "Game Versions & Betas" -> Select "Fullpackage" from the drop-down menu.
  • Select "Fullpackage" to download the full package on Steam.
  • When the download is completed, select "Play Wuthering Waves - fullpackage" as your launch option to start the game.
  • Please note that the game content is identical between the two modes, and account data is fully shared.
  • The only differences lie in the download and launch methods.
  • You are free to choose your preferred option, and the actual game content will not be affected.
