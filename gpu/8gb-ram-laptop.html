How this list is matched

Every entry comes from the official minimum and recommended requirements published on each game's Steam store page. We compare the GPU and RAM each game asks for against the hardware in this guide, and mark a game 60 FPS at recommended settings only when its recommended requirement is met, or playable at minimum when only the minimum is met.

GPU tiers are ordered by approximate 1080p relative performance, so a card is compared against the required card rather than by name. Requirements that only name a VRAM size ("2 GB VRAM") are placed on the same scale. Where Steam publishes no recommended GPU, the game is never marked as 60 FPS recommended.

Lists are sorted by Steam review count, so the most played games come first. Counts are rebuilt every time the database grows — see the full hardware filter for an exact match against your own GPU, RAM and frame target.

Frequently asked questions

Is 8 GB of RAM enough for gaming in 2026?

For the games in the first list, yes. Most current releases list 16 GB at recommended settings, so they appear in the minimum-spec list here or not at all.

Will adding RAM to 16 GB unlock more games?

It moves every game that lists 16 GB at recommended settings into the 60 FPS list, which is the majority of recent releases. It does not change the GPU limit.

How many games run on this hardware?

11,888 games list recommended requirements this hardware meets, and 2,301 more are playable at minimum settings. Counts come from the current database of 15,488 games.
