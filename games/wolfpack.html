Hardware & Performance Analysis

Both rows of the requirement table for Wolfpack list "Direct X 11 compliant card": there is no faster card to buy for the recommended tier. What separates 1080p @ 30 FPS (Low Settings) from 1080p @ 60 FPS (High Settings) is resolution and preset, not silicon.

The publisher states no memory figure, so plan on 8 GB as a safe floor and 16 GB if you play with other applications open. The 10 GB install fits on any drive made this decade without a second thought. DirectX 11 keeps anything from the GTX 400 era onward in scope.

Steam Deck lists it as Playable, so the game runs there while some text and inputs need a closer look. A 2019 release also means current drivers already carry a profile for it.
