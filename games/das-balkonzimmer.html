Hardware & Performance Analysis

Das Balkonzimmer asks for "Onboard Graphics" at minimum and "NVIDEA GTX 1060" at its recommended settings. One of those rows names a category rather than a specific card, so it cannot be placed on a card index with confidence; treat the store's wording as the requirement and the rows above as the comparison.

The publisher states no memory figure, so plan on 8 GB as a safe floor and 16 GB if you play with other applications open. At 2 GB the download is trivial, so storage planning does not enter the decision.

Steam Deck lists it as Playable, so the game runs there while some text and inputs need a closer look. A 2020 release also means current drivers already carry a profile for it.
