Hardware & Performance Analysis

The two requirement rows for Medieval Kingdom Wars ("NVIDIA GeForce 670" and "NVIDIA GeForce GTX 970") come out in the same class on our index, which makes the recommended column a settings target. Treat the pair as one hardware floor: a machine that clears the first row is not changed much by the second.

Memory climbs from 3 GB to 5 GB, a step a machine with 8 GB covers without leaning on the page file. At 7 GB the download is trivial, so storage planning does not enter the decision. DirectX 11 keeps anything from the GTX 400 era onward in scope.

That lands in mainstream territory (GTX 1060 3Gb bracket), where 1080p on medium to high is the realistic target and the card you already own is usually the question rather than the upgrade. Steam Deck lists it as Playable, so the game runs there while some text and inputs need a closer look. A 2019 release also means current drivers already carry a profile for it.
