Hardware & Performance Analysis

Feign names the same GPU, "Graphics card with DX10 (shader model 4.0) capabilities", in both requirement columns, so the recommended tier is a settings target rather than a hardware upgrade. The whole gap is spent on 1080p @ 60 FPS (High Settings) versus 1080p @ 30 FPS (Low Settings), and the card it asks for does not change.

The publisher states no memory figure, so plan on 8 GB as a safe floor and 16 GB if you play with other applications open. At 799 MB the download is trivial, so storage planning does not enter the decision. DirectX 10 is unusual for a 2025 release and normally means a 2D or deliberately retro renderer.

On Steam Deck it is rated Playable rather than Verified: it runs, but small text or the default control layout may need adjusting. Released in 2025, it was built against current driver branches, so a supported card with an up-to-date driver is enough.
