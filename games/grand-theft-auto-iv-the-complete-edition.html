Hardware & Performance Analysis

Grand Theft Auto IV: The Complete Edition names the same GPU, "256MB Nvidia 7900", in both requirement columns, so the recommended tier is a settings target rather than a hardware upgrade. Between 1080p @ 30 FPS (Low Settings) and 1080p @ 60 FPS (High Settings) the difference is preset and frame rate, and the same GPU carries both.

Both tiers settle on 1.5 GB of memory, which means memory is not the constraint here at all. The 22 GB install fits on any drive made this decade without a second thought.

On Steam Deck it is rated Playable rather than Verified: it runs, but small text or the default control layout may need adjusting. A 2020 release also means current drivers already carry a profile for it.
