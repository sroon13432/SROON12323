Hardware & Performance Analysis

The minimum and recommended rows for Simultree are built around one card, "Integrated graphics", which means the publisher scales settings rather than hardware. The whole gap is spent on 1080p @ 60 FPS (High Settings) versus 1080p @ 30 FPS (Low Settings), and the card it asks for does not change.

The publisher states no memory figure, so plan on 8 GB as a safe floor and 16 GB if you play with other applications open. At 1 GB the download is trivial, so storage planning does not enter the decision.

That tier is integrated-graphics territory by our index, so the interesting questions are storage and operating system support rather than the graphics card. Steam Deck lists it as Playable, so the game runs there while some text and inputs need a closer look. Released in 2026, it was built against current driver branches, so a supported card with an up-to-date driver is enough.
