Hardware & Performance Analysis

The store page for this title publishes no GPU figure, so the requirement cannot be placed on our tier index at all. The table carries the operating system, memory and storage rows only, and the publisher's own page is the place to confirm hardware before buying an upgrade.

Both tiers settle on 4 GB of memory, which means memory is not the constraint here at all. At 696 MB the download is trivial, so storage planning does not enter the decision.

That tier is integrated-graphics territory by our index, so the interesting questions are storage and operating system support rather than the graphics card. Steam Deck lists it as Playable, so the game runs there while some text and inputs need a closer look. Released in 2024, it was built against current driver branches, so a supported card with an up-to-date driver is enough.
