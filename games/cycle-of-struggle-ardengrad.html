Hardware & Performance Analysis

Cycle of Struggle: Ardengrad names the same GPU, "2 GB VRAM", in both requirement columns, so the recommended tier is a settings target rather than a hardware upgrade. What separates 1080p @ 30 FPS (Low Settings) from 1080p @ 60 FPS (High Settings) is resolution and preset, not silicon.

Both tiers settle on 4 GB of memory, which means memory is not the constraint here at all. At 4 GB the download is trivial, so storage planning does not enter the decision. DirectX 11 keeps anything from the GTX 400 era onward in scope.

Steam Deck lists it as Playable, so the game runs there while some text and inputs need a closer look. Released in 2026, it was built against current driver branches, so a supported card with an up-to-date driver is enough.
