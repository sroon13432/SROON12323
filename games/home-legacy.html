Hardware & Performance Analysis

Both rows of the requirement table for Home Legacy list "DirectX 11 compatible graphics card": there is no faster card to buy for the recommended tier. The whole gap is spent on 1080p @ 60 FPS (High Settings) versus 1080p @ 30 FPS (Low Settings), and the card it asks for does not change.

Memory holds at 16 GB in both columns, so a 16 GB machine has nothing to fix before installing. The 10 GB install fits on any drive made this decade without a second thought. DirectX 11 keeps anything from the GTX 400 era onward in scope.

Steam Deck marks it Unsupported, the grade Steam gives when anti-cheat or a launcher stands between the game and the handheld. A 2017 release also means current drivers already carry a profile for it.
