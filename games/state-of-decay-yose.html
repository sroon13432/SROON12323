Hardware & Performance Analysis

The requirement table for State of Decay: YOSE runs from "GeForce GTX 470" in the minimum column to "GeForce GTX 560" in the recommended one. On our relative index that is Legacy to Very low-end, something like 60% more headroom. Read the recommended row as the configuration that makes 1080p @ 60 FPS (High Settings) realistic, and the minimum as the one that only starts the game at 1080p @ 30 FPS (Low Settings).

Memory climbs from 4 GB to 8 GB, a step a machine with 8 GB covers without leaning on the page file. At 4.1 GB the download is trivial, so storage planning does not enter the decision. DirectX 11 keeps anything from the GTX 400 era onward in scope.

The figure is in the lowest band of our index, so any working card of that generation meets it and the row is closer to a formality than a target. Steam Deck lists it as Playable, so the game runs there while some text and inputs need a closer look.
