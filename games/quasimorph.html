Hardware & Performance Analysis

Quasimorph names the same GPU, "NVIDIA GeForce GTX 760", in both requirement columns, so the recommended tier is a settings target rather than a hardware upgrade. What separates 1080p @ 30 FPS (Low Settings) from 1080p @ 60 FPS (High Settings) is resolution and preset, not silicon.

Both tiers settle on 2 GB of memory, which means memory is not the constraint here at all. At 297 MB the download is trivial, so storage planning does not enter the decision.

That is low-end discrete-card territory (GTX 760 bracket), where 1080p is comfortable as long as the preset stays modest. Valve grades it Steam Deck Verified, so the interface, text and controls are all confirmed for the 1280x800 handheld screen. Released in 2026, it was built against current driver branches, so a supported card with an up-to-date driver is enough.
