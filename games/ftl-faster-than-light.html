Hardware & Performance Analysis

FTL: Faster Than Light names the same GPU, "1280x720 minimum resolution, OpenGL 2.0 Support,", in both requirement columns, so the recommended tier is a settings target rather than a hardware upgrade. The whole gap is spent on 1080p @ 60 FPS (High Settings) versus 1080p @ 30 FPS (Low Settings), and the card it asks for does not change.

Both tiers settle on 1 GB of memory, which means memory is not the constraint here at all. At 174 MB the download is trivial, so storage planning does not enter the decision.

Steam Deck lists it as Playable, so the game runs there while some text and inputs need a closer look. Released in 2012, it predates the modern driver stack; if it refuses to launch, compatibility mode and a community patch are the usual first stops.
