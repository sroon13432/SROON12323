Hardware & Performance Analysis

The minimum and recommended rows for Cosmic Miners are built around one card, "AMD Radeon RX 5700, NVIDIA GeForce 1070 Ti", which means the publisher scales settings rather than hardware. The whole gap is spent on 1080p @ 60 FPS (High Settings) versus 1080p @ 30 FPS (Low Settings), and the card it asks for does not change.

Both tiers settle on 4 GB of memory, which means memory is not the constraint here at all. The 9.77 GB install fits on any drive made this decade without a second thought. DirectX 11 keeps anything from the GTX 400 era onward in scope.

That is mid-range by our index (GTX 1070 Ti bracket), the band the publisher's 1080p target is written for. Steam Deck lists it as Playable, so the game runs there while some text and inputs need a closer look. Released in 2025, it was built against current driver branches, so a supported card with an up-to-date driver is enough.
