Hardware & Performance Analysis

Both rows of the requirement table for ANYKEY list "Integrated graphics with 512MB+ of VRam": there is no faster card to buy for the recommended tier. Between 1080p @ 30 FPS (Low Settings) and 1080p @ 60 FPS (High Settings) the difference is preset and frame rate, and the same GPU carries both.

Both tiers settle on 0.5 GB of memory, which means memory is not the constraint here at all. At 41 MB the download is trivial, so storage planning does not enter the decision. DirectX 9 is unusual for a 2018 release and normally means a 2D or deliberately retro renderer.

In our index that recommended card sits in integrated-graphics territory, which is the honest reason this title turns up on low-end lists: the GPU is almost never the obstacle. On Steam Deck it is rated Playable rather than Verified: it runs, but small text or the default control layout may need adjusting. A 2018 release also means current drivers already carry a profile for it.
