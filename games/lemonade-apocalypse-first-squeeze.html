Hardware & Performance Analysis

Both rows of the requirement table for Lemonade Apocalypse: First Squeeze list "Integrated graphics processors": there is no faster card to buy for the recommended tier. Between 1080p @ 30 FPS (Low Settings) and 1080p @ 60 FPS (High Settings) the difference is preset and frame rate, and the same GPU carries both.

Both tiers settle on 1 GB of memory, which means memory is not the constraint here at all. At 143 MB the download is trivial, so storage planning does not enter the decision.

That tier is integrated-graphics territory by our index, so the interesting questions are storage and operating system support rather than the graphics card. On Steam Deck it is rated Playable rather than Verified: it runs, but small text or the default control layout may need adjusting. Released in 2024, it was built against current driver branches, so a supported card with an up-to-date driver is enough.
