Minecraft: Java Edition

💾 2 GB minimum, 4 GB recommended ⚙️ Java Edition (Lightweight Java Game Library)

Minecraft: Java Edition is Mojang's original PC build, bought and launched through the Minecraft Launcher rather than Steam. Mojang raised both requirements in July 2026: the minimum target is now 1080p at 30 FPS on the Fast preset with a 4-core CPU, 8 GB of RAM (12 GB with integrated graphics) and a Vulkan 1.3 GPU with 2 GB of VRAM; the recommended target is 1080p at 60 FPS on Fancy with 16 GB and a 6 GB card such as an RTX 2060.

🚀 Recommended GPU: NVIDIA GeForce RTX 2060 / AMD Radeon RX 5600 XT / Intel Arc A580

Best Graphic Settings & FPS Boost Tips

  • 💡
    Java Edition is still CPU-bound: Mojang's own comparison page notes the game depends more on the processor than the graphics card, so the 4-core minimum matters more than a faster GPU.
  • 💡
    Mojang is moving the renderer from OpenGL to Vulkan, which is why the minimum is now a Vulkan 1.3 card with 2 GB of VRAM; an older OpenGL-only card may still launch but is no longer supported.
  • 💡
    Step down from Fancy to Fast before touching render distance: the published targets are built around exactly those two presets (30 FPS on Fast, 60 FPS on Fancy).
  • 💡
    Mods and large worlds add their own memory cost on top of the 2 GB install figure, so leave RAM headroom above the published 8 GB or 16 GB.

Frequently Asked Questions

Can my PC run Minecraft: Java Edition?

Minecraft: Java Edition lists Vulkan 1.3 GPU with 2 GB VRAM (GeForce GTX 950 / Radeon RX 460 / Arc A310 or newer) and 8 GB (12 GB with integrated graphics) RAM as its minimum, and NVIDIA GeForce RTX 2060 / AMD Radeon RX 5600 XT / Intel Arc A580 with 16 GB RAM as its recommended specification.

What GPU do I need for Minecraft: Java Edition at 60 FPS?

The recommended GPU is NVIDIA GeForce RTX 2060 / AMD Radeon RX 5600 XT / Intel Arc A580. That is the configuration the publisher targets for Official recommended (1080p @ 60 FPS, Fancy preset).

How much RAM does Minecraft: Java Edition need?

8 GB (12 GB with integrated graphics) of memory at minimum and 16 GB at recommended settings.

How much storage does Minecraft: Java Edition need?

2 GB available space.
