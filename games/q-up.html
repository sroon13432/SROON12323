Hardware & Performance Analysis

The minimum and recommended rows for Q-UP are built around one card, "OpenGL 2.1 compatible graphics card, integrated graphics", which means the publisher scales settings rather than hardware. What separates 1080p @ 30 FPS (Low Settings) from 1080p @ 60 FPS (High Settings) is resolution and preset, not silicon.

Both tiers settle on 1 GB of memory, which means memory is not the constraint here at all. At 2 GB the download is trivial, so storage planning does not enter the decision.

That tier is integrated-graphics territory by our index, so the interesting questions are storage and operating system support rather than the graphics card. Steam Deck lists it as Playable, so the game runs there while some text and inputs need a closer look. Released in 2025, it was built against current driver branches, so a supported card with an up-to-date driver is enough.
