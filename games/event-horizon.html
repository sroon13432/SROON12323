Hardware & Performance Analysis

The minimum and recommended rows for Event Horizon are built around one card, "DirectX 9 compatible graphics card", which means the publisher scales settings rather than hardware. Between 1080p @ 30 FPS (Low Settings) and 1080p @ 60 FPS (High Settings) the difference is preset and frame rate, and the same GPU carries both.

Memory does not move between the tiers and stays at 0.5 GB, small even by laptop standards, so RAM is not where this title will strain a machine. At 102 MB the download is trivial, so storage planning does not enter the decision. DirectX 9 is unusual for a 2018 release and normally means a 2D or deliberately retro renderer.

On Steam Deck it is rated Playable rather than Verified: it runs, but small text or the default control layout may need adjusting. A 2018 release also means current drivers already carry a profile for it.
