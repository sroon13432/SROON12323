Hardware & Performance Analysis

Both rows of the requirement table for StrikeForce Kitty list "Radeon HD": there is no faster card to buy for the recommended tier. Between 1080p @ 30 FPS (Low Settings) and 1080p @ 60 FPS (High Settings) the difference is preset and frame rate, and the same GPU carries both.

Memory climbs from 1 GB to 2 GB, a step a machine with 8 GB covers without leaning on the page file. At 1004 MB the download is trivial, so storage planning does not enter the decision. DirectX 9 is unusual for a 2018 release and normally means a 2D or deliberately retro renderer.

On Steam Deck it is rated Playable rather than Verified: it runs, but small text or the default control layout may need adjusting. A 2018 release also means current drivers already carry a profile for it.
