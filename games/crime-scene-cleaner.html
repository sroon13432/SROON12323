Hardware & Performance Analysis

Crime Scene Cleaner names the same GPU, "RTX 2070 SUPER (Integrated Graphic Cards are not supported)", in both requirement columns, so the recommended tier is a settings target rather than a hardware upgrade. The whole gap is spent on 1080p @ 60 FPS (High Settings) versus 1080p @ 30 FPS (Low Settings), and the card it asks for does not change.

Memory holds at 16 GB in both columns, so a 16 GB machine has nothing to fix before installing. The 35 GB install fits on any drive made this decade without a second thought.

That is upper mid-range (RTX 2070 Super bracket), so the target settings are realistic but the upgrade conversation has to include the CPU beside the card. Steam Deck lists it as Playable, so the game runs there while some text and inputs need a closer look. Released in 2024, it was built against current driver branches, so a supported card with an up-to-date driver is enough.
