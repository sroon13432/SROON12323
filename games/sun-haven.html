Hardware & Performance Analysis

Both rows of the requirement table for Sun Haven list "3GB Video Memory": there is no faster card to buy for the recommended tier. Between 1080p @ 30 FPS (Low Settings) and 1080p @ 60 FPS (High Settings) the difference is preset and frame rate, and the same GPU carries both.

Both tiers settle on 4 GB of memory, which means memory is not the constraint here at all. The 10 GB install fits on any drive made this decade without a second thought. DirectX 10 is unusual for a 2023 release and normally means a 2D or deliberately retro renderer.

On Steam Deck it is rated Playable rather than Verified: it runs, but small text or the default control layout may need adjusting. A 2023 release also means current drivers already carry a profile for it.
