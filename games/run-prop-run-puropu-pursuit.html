Hardware & Performance Analysis

Run Prop, Run! - Puropu Pursuit asks for "Nvidia 450" at minimum and "Nvidia 970/AMD 390" at its recommended settings. One of those rows names a category rather than a specific card, so it cannot be placed on a card index with confidence; treat the store's wording as the requirement and the rows above as the comparison.

Memory climbs from 2 GB to 4 GB, a step a machine with 8 GB covers without leaning on the page file. At 502 MB the download is trivial, so storage planning does not enter the decision. DirectX 9 is unusual for a 2021 release and normally means a 2D or deliberately retro renderer.

On Steam Deck it is rated Playable rather than Verified: it runs, but small text or the default control layout may need adjusting. A 2021 release also means current drivers already carry a profile for it.
