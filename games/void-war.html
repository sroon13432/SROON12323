Hardware & Performance Analysis

Void War asks for "1GB VRAM" at minimum and "2GB VRAM" at its recommended settings. One of those rows names a category rather than a specific card, so it cannot be placed on a card index with confidence; treat the store's wording as the requirement and the rows above as the comparison.

Memory climbs from 4 GB to 8 GB, a step a machine with 8 GB covers without leaning on the page file. At 246 MB the download is trivial, so storage planning does not enter the decision.

Steam Deck lists it as Playable, so the game runs there while some text and inputs need a closer look. Released in 2025, it was built against current driver branches, so a supported card with an up-to-date driver is enough.
