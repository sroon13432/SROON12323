Hardware & Performance Analysis

The Aquarium does not dance names the same GPU, "Compatible OpenGL", in both requirement columns, so the recommended tier is a settings target rather than a hardware upgrade. What separates 1080p @ 30 FPS (Low Settings) from 1080p @ 60 FPS (High Settings) is resolution and preset, not silicon.

Memory holds at 8 GB in both columns, which an 8 GB machine meets without swapping. At 399 MB the download is trivial, so storage planning does not enter the decision.

It is Steam Deck Verified, which means text size and controls were checked on the handheld rather than assumed. Released in 2024, it was built against current driver branches, so a supported card with an up-to-date driver is enough.
