Hardware & Performance Analysis

Last Wood names the same GPU, "Intel HD 4600 (AMD)", in both requirement columns, so the recommended tier is a settings target rather than a hardware upgrade. The whole gap is spent on 1080p @ 60 FPS (High Settings) versus 1080p @ 30 FPS (Low Settings), and the card it asks for does not change.

Both tiers settle on 4 GB of memory, which means memory is not the constraint here at all. At 502 MB the download is trivial, so storage planning does not enter the decision.

In our index that recommended card sits in integrated-graphics territory, which is the honest reason this title turns up on low-end lists: the GPU is almost never the obstacle. Steam Deck lists it as Playable, so the game runs there while some text and inputs need a closer look. A 2022 release also means current drivers already carry a profile for it.
