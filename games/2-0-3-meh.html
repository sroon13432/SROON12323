Hardware & Performance Analysis

[2.0.3] MEH 🖥️ names the same GPU, "Nvidia Gt", in both requirement columns, so the recommended tier is a settings target rather than a hardware upgrade. What separates 1080p @ 30 FPS (Low Settings) from 1080p @ 60 FPS (High Settings) is resolution and preset, not silicon.

Both tiers settle on 1 GB of memory, which means memory is not the constraint here at all. At 102 MB the download is trivial, so storage planning does not enter the decision.

Valve grades it Steam Deck Verified, so the interface, text and controls are all confirmed for the 1280x800 handheld screen. Released in 2024, it was built against current driver branches, so a supported card with an up-to-date driver is enough.
