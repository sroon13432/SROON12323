Hardware & Performance Analysis

Between its two tiers Time Machine VR moves from "GeForce GTX 970 GPU (or equivalent)" to "GeForce GTX 980 GPU (or equivalent)". Both rows sit in the Entry-level gaming band on our index, and the step between them is a modest step, the same class of card with more room to spare. Read the recommended row as the configuration that makes 1080p @ 60 FPS (High Settings) realistic, and the minimum as the one that only starts the game at 1080p @ 30 FPS (Low Settings).

The publisher states no memory figure, so plan on 8 GB as a safe floor and 16 GB if you play with other applications open. No storage figure is published, so check the store listing before dedicating a drive to it.

That lands in mainstream territory (GTX 980 bracket), where 1080p on medium to high is the realistic target and the card you already own is usually the question rather than the upgrade.

Every figure above comes from this title's published requirements. How the tiers and estimates are produced is explained in our editorial methodology.

Frequently Asked Questions

Can my PC run Time Machine VR?

Time Machine VR lists GeForce GTX 970 GPU (or equivalent) and RAM as its minimum, and GeForce GTX 980 GPU (or equivalent) with RAM as its recommended specification.

What GPU do I need for Time Machine VR at 60 FPS?

The recommended GPU is GeForce GTX 980 GPU (or equivalent). That is the configuration the publisher targets for 1080p @ 60 FPS (High Settings).

How much RAM does Time Machine VR need?

The store page does not state a memory requirement. 16 GB covers every game in this database at recommended settings.

How much storage does Time Machine VR need?

Neither requirement tier states a storage figure; check the game's official system requirements page before installing.
