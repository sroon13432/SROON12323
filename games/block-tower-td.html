Frequently Asked Questions

Can my PC run Block Tower TD?

Block Tower TD lists 1 GB video memory and RAM as its minimum, and 1 GB video memory with RAM as its recommended specification.

What GPU do I need for Block Tower TD at 60 FPS?

The recommended GPU is 1 GB video memory. That is the configuration the publisher targets for 1080p @ 60 FPS (High Settings).

How much RAM does Block Tower TD need?

The store page does not state a memory requirement. 16 GB covers every game in this database at recommended settings.

How much storage does Block Tower TD need?

Neither requirement tier states a storage figure; check the game's official system requirements page before installing.
