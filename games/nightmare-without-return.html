Hardware & Performance Analysis

梦魇：无归 Nightmare without return names the same GPU, "any type", in both requirement columns, so the recommended tier is a settings target rather than a hardware upgrade. What separates 1080p @ 30 FPS (Low Settings) from 1080p @ 60 FPS (High Settings) is resolution and preset, not silicon.

The publisher states no memory figure, so plan on 8 GB as a safe floor and 16 GB if you play with other applications open. The 10 GB install fits on any drive made this decade without a second thought.

Steam Deck marks it Unsupported, the grade Steam gives when anti-cheat or a launcher stands between the game and the handheld. A 2022 release also means current drivers already carry a profile for it.
