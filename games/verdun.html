Hardware & Performance Analysis

The two requirement rows for Verdun run from "Geforce GTX 960M" to "4GB video card memory". One of those rows names a category rather than a specific card, so it cannot be placed on a card index with confidence; treat the store's wording as the requirement and the rows above as the comparison.

Memory climbs from 4 GB to 8 GB, a step a machine with 8 GB covers without leaning on the page file. The 12 GB install fits on any drive made this decade without a second thought. DirectX 10 dates the target hardware to cards from the late 2000s.

Steam Deck lists it as Playable, so the game runs there while some text and inputs need a closer look. Released in 2015, it predates the modern driver stack; if it refuses to launch, compatibility mode and a community patch are the usual first stops.
