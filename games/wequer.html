Hardware & Performance Analysis

Wequer names the same GPU, "256MB", in both requirement columns, so the recommended tier is a settings target rather than a hardware upgrade. Between 1080p @ 30 FPS (Low Settings) and 1080p @ 60 FPS (High Settings) the difference is preset and frame rate, and the same GPU carries both.

Memory does not move between the tiers and stays at 0.5 GB, small even by laptop standards, so RAM is not where this title will strain a machine. At 246 MB the download is trivial, so storage planning does not enter the decision.

Steam Deck lists it as Playable, so the game runs there while some text and inputs need a closer look. A 2019 release also means current drivers already carry a profile for it.
