Hardware & Performance Analysis

Both rows of the requirement table for Teacup list "Intel HD 4000": there is no faster card to buy for the recommended tier. The whole gap is spent on 1080p @ 60 FPS (High Settings) versus 1080p @ 30 FPS (Low Settings), and the card it asks for does not change.

Memory holds at 8 GB in both columns, which an 8 GB machine meets without swapping. At 3 GB the download is trivial, so storage planning does not enter the decision.

In our index that recommended card sits in integrated-graphics territory, which is the honest reason this title turns up on low-end lists: the GPU is almost never the obstacle. Steam Deck lists it as Playable, so the game runs there while some text and inputs need a closer look. A 2021 release also means current drivers already carry a profile for it.
