Hardware & Performance Analysis

Both rows of the requirement table for Broken Sword 2 - the Smoking Mirror: Remastered (2010) list "Direct X 5.0 compatible card": there is no faster card to buy for the recommended tier. Between 1080p @ 30 FPS (Low Settings) and 1080p @ 60 FPS (High Settings) the difference is preset and frame rate, and the same GPU carries both.

Both tiers settle on 0.5 GB of memory, which means memory is not the constraint here at all. At 604 MB the download is trivial, so storage planning does not enter the decision.

Valve grades it Steam Deck Verified, so the interface, text and controls are all confirmed for the 1280x800 handheld screen. Released in 2009, it predates the modern driver stack; if it refuses to launch, compatibility mode and a community patch are the usual first stops.
