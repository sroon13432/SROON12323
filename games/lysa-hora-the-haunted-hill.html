Hardware & Performance Analysis

The two requirement rows for LYSA HORA: The Haunted Hill run from "NVIDIA GeForce GTX 8GB" to "NVIDIA GeForce RTX 16GB". One of those rows names a category rather than a specific card, so it cannot be placed on a card index with confidence; treat the store's wording as the requirement and the rows above as the comparison.

Memory is the second place the tiers separate: 8 GB at minimum against 32 GB recommended, and the higher figure is the one that matters once a browser shares the machine. The 8 GB install fits on any drive made this decade without a second thought. The DirectX 12 row also sets a hardware floor: cards from before roughly 2015 do not implement it.

Steam Deck lists it as Playable, so the game runs there while some text and inputs need a closer look. Released in 2026, it was built against current driver branches, so a supported card with an up-to-date driver is enough.

Every figure above comes from this title's published requirements. How the tiers and estimates are produced is explained in our editorial methodology.
