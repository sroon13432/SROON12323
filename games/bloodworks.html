Hardware & Performance Analysis

Both rows of the requirement table for Bloodworks list "OpenGL 3.2": there is no faster card to buy for the recommended tier. Between 1080p @ 30 FPS (Low Settings) and 1080p @ 60 FPS (High Settings) the difference is preset and frame rate, and the same GPU carries both.

Memory does not move between the tiers and stays at 0.5 GB, small even by laptop standards, so RAM is not where this title will strain a machine. At 256 MB the download is trivial, so storage planning does not enter the decision.

Steam Deck compatibility is listed as Unsupported, usually because of anti-cheat, a launcher, or controls that do not map to the handheld. A 2017 release also means current drivers already carry a profile for it.
