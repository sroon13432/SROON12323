Hardware & Performance Analysis

PIGFACE names the same GPU, "Geforce GTX 960", in both requirement columns, so the recommended tier is a settings target rather than a hardware upgrade. The whole gap is spent on 1080p @ 60 FPS (High Settings) versus 1080p @ 30 FPS (Low Settings), and the card it asks for does not change.

Memory holds at 8 GB in both columns, which an 8 GB machine meets without swapping. At 5 GB the download is trivial, so storage planning does not enter the decision. DirectX 11 keeps anything from the GTX 400 era onward in scope.

That is low-end discrete-card territory (GTX 960 bracket), where 1080p is comfortable as long as the preset stays modest. On Steam Deck it is rated Playable rather than Verified: it runs, but small text or the default control layout may need adjusting. Released in 2025, it was built against current driver branches, so a supported card with an up-to-date driver is enough.
