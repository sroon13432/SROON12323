Contact

Contact CanMySpec

One address reaches the editor for everything below: corrections, missing games, broken pages, copyright requests, advertising and data questions.

contact@canmyspec.com

English, Korean and Japanese are all fine. There is no phone line and no office address: CanMySpec is run by one independent editor, and email is the only channel that reaches a person rather than a queue.

Report a wrong requirement or rating

Send the page address, the field that is wrong (minimum GPU, recommended memory, storage, release date, rating), and a link to the publisher's or store's page that shows the correct figure. Screenshots help when the store page changes often. A reported correction is checked against the store record and, if it holds, changed on the page and carried to the rest of the catalogue with the next build.

Request a game that is missing

Send the title and its store link. Games sold on Steam are added automatically as the catalogue grows, but a request puts a title on the list. Titles that publish no requirement information at all — many console and mobile-only releases — are not added, because a page with nothing but a store link would be a thin page rather than an answer.

Report a broken page or a rendering problem

Include the address, the device and browser you are using, and what you expected to see. Mobile layout problems in particular are worth reporting: the page should fit a 390 px screen without sideways scrolling.

Copyright or takedown

Game titles, screenshots, store images and trademarks belong to their owners. If you are a rights holder and want an image or a trademark use removed, write from an address associated with the rights holder, name the page, and identify the material. Such requests are handled first and without argument.

Advertising, partnerships and press

Advertising on the site is served through Google AdSense; direct advertising is not sold. Editorial inclusion is never paid for, so please do not write to offer payment for a listing, a ranking or a better verdict. Press and research requests are welcome; if you need the source of a specific figure, say which page and which number.

Privacy and data requests

CanMySpec keeps no visitor accounts and no database of readers. For a request about analytics or advertising data, or to exercise any right described in the privacy policy, write to the same address and say what you are asking for and where you are located.

How long a reply takes

Corrections and takedown requests are read first; most other messages get a reply within a few business days. If a message needs no reply — a correction that has already been applied, for instance — the fix will appear on the page without a separate note.

Before writing, the editorial methodology may already answer the question: it explains what each requirement column promises, how the GPU tiers and estimates are calculated, and why a game can meet its recommended spec and still stutter.
